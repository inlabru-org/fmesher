# Calculate the area inside segments

Calculate the (signed) area inside `fm_segm` boundary objects.

## Usage

``` r
fm_area(x, ...)

# S3 method for class 'fm_segm'
fm_area(x, ...)

# S3 method for class 'fm_segm_list'
fm_area(x, ...)
```

## Arguments

- x:

  Object for which to calculate the area

- ...:

  Currently unused
